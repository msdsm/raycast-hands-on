# Raycast Todo App

A simple todo list manager for Raycast.

## Features

- ✅ Add new todos
- ✅ Toggle todo completion
- ✅ Delete todos
- ✅ Persistent storage

## Usage

1. Open Raycast
2. Type `raycast-hands-on`
3. View your todo list
4. Select "Create New Todo" to add a new item

## Development

```bash
npm install
npm run dev
```
